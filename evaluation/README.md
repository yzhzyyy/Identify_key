`colRunTime/` Stores plots and outputs for the **runtime experiments w.r.t. the number of columns** (column-combination size).

`precision_recall/` Stores the outputs for the **precision/recall evaluation**, including classification results and summary tables.

`rowRunTime/` Stores plots and outputs for the **runtime experiments w.r.t. the number of rows** (table size).

`change_col.ipynb` Notebook for running the **column-based runtime experiment** (how UR computation time changes as the number of columns increases).

`change_row.ipynb` Notebook for running the **row-based runtime experiment** (how UR computation time changes as the number of rows increases).
