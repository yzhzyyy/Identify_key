This directory contains the experiment outputs generated by `hockey_analysis.ipynb`.

`ur_result/` Stores the **Uniqueness Ratio (UR) / Completeness Ratio (CR)** computation results for each table in the Hockey database. Each table is saved as: `{table_name}_result.csv`


`near_key_all.csv` A summary file containing all extracted **near-keys** from the Hockey database. This file is used as the input for later steps such as specialisation analysis and counter-example analysis.


`specialisation_result/` Stores the generated **specialisation lattice graphs** for selected keys (typically those with `UR(max) = 1.0`).


`specialisation_time_result/` Stores the runtime comparison figures for different specialisation strategies (e.g., **Normal / BFS / DFS**).


`counter_example_result/` Stores the outputs of **data duplication visualisation** and **counter-example analysis**.


`hockey_analysis.ipynb`
The main Jupyter Notebook that runs the full experimental pipeline, including:
1. Computing UR/CR for all column combinations (`ur_result/`)
2. Extracting near-keys (`near_key_all.csv`)
3. Specialisation analysis (`specialisation_result/`, `specialisation_time_result/`)
4. Counter-example analysis (`counter_example_result/`)
